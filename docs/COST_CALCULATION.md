# Расчёт себестоимости рейса — версия 1

Это демонстрационная управленческая модель. Правила конкретной компании,
налоговый учёт, начисление зарплаты и юридические требования не моделируются.
Все суммы примера выражены в RUB без налогов. Поля и ставки — вымышленные.

## Входы

| Поле | Единица и смысл |
|---|---|
| loaded_km, empty_km | Км с грузом и без груза; оба входят в общую дистанцию |
| fuel_l_per_100km | Единая норма расхода на весь пробег |
| fuel_price_per_l | Цена литра в валюте расчёта |
| driver_hours, driver_rate_per_hour | Оплачиваемое время, включая предусмотренные простои |
| maintenance_per_km | Резерв на обслуживание за км |
| depreciation_per_km | Амортизация за км |
| tolls, other_direct | Платные дороги и остальные прямые расходы |
| overhead_rate | Доля прямых затрат: 0.10 означает 10% |
| target_margin | Целевая маржа от цены: 0.20 означает 20% |
| revenue | Необязательная выручка для расчёта ожидаемой прибыли |

Все числовые входы передаются строками с точкой, без разделителей тысяч.
Пустое поле не равно нулю. Отрицательные, NaN, бесконечные значения и неизвестные
поля отвергаются. Для переносимого примера: не более 6 дробных знаков, величина
меньше 10^12; overhead_rate от 0 до 1, target_margin от 0 включительно до 1
исключительно. Нулевой пробег допустим для фиксированных/временных расходов,
но cost_per_km возвращается null.

## Формулы

```text
D = loaded_km + empty_km
L = D × fuel_l_per_100km / 100
Fuel = L × fuel_price_per_l
Driver = driver_hours × driver_rate_per_hour
Maintenance = D × maintenance_per_km
Depreciation = D × depreciation_per_km
Direct = Fuel + Driver + Maintenance + Depreciation + tolls + other_direct
Overhead = Direct × overhead_rate
Total = Direct + Overhead
Price = Total / (1 − target_margin)
Profit = revenue − Total
Actual_margin = Profit / revenue, только если revenue > 0
```

Политика округления: Decimal, ROUND_HALF_UP; каждая денежная строка округляется
до 0.01, Direct суммирует округлённые строки. Overhead округляется отдельно от
Direct. Total равен сумме отображённых Direct и Overhead. Цена округляется вверх
до 0.01, чтобы округление не уменьшило целевую маржу. Cost_per_km округляется
до 0.01 для отображения; не используйте его для обратного расчёта Total.
Revenue также округляется до 0.01 до вычисления Profit и Actual_margin.
Actual_margin выводится долей с шестью дробными знаками; при нулевой выручке — null.

Маржа 20% отличается от наценки 20%: цена = себестоимость / 0.8, а не × 1.2.
Округление и масштаб — часть версии формулы, а не настройка отображения.

## Проверяемый пример

Для `examples/trip-cost.json`: 500 км с грузом + 100 км порожняком, расход
30 л/100 км, топливо 60 RUB/л, водитель 12 ч × 400, обслуживание 4 RUB/км,
амортизация 3 RUB/км, дороги 1500, прочие расходы 500, накладные 10%.

| Результат | Значение |
|---|---:|
| Пробег / топливо | 600 км / 180 л |
| Топливо | 10800.00 |
| Водитель | 4800.00 |
| Обслуживание / амортизация | 2400.00 / 1800.00 |
| Прямые расходы | 21800.00 |
| Накладные | 2180.00 |
| Себестоимость | 23980.00 |
| Себестоимость за км | 39.97 |
| Цена при марже 20% | 29975.00 |
| Прибыль при выручке 30000 | 6020.00 |
| Фактическая маржа при этой выручке | 0.200667 |

Запуск: `python scripts/calculate_trip.py examples/trip-cost.json`.
Тесты: `python -m unittest discover -s tests -v`.

В продукте сохраняйте tenant, trip, currency, версию формулы, снимок входов,
версию тарифа, автора и время расчёта. План и факт храните отдельно.
Не складывайте уже включённое топливо, зарплату или налоги повторно через
other_direct. Возвраты оформляйте отдельными корректировками; этот калькулятор
отрицательные расходы не принимает. Фактический расход топлива и разные нормы
для порожнего/гружёного пробега потребуют новой явно описанной версии формулы.
