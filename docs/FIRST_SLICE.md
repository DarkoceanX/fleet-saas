# Первая вертикаль — локальная основа Fleet SaaS

Результат: пользователь входит в свою организацию, создаёт машину и рейс,
сохраняет плановую себестоимость и повторно читает неизменяемый снимок из PostgreSQL.
Исходной ветки/commit нет: starter распакован без .git. Соседние проекты не меняются.

## План

1. Проверить инструменты, сохранить эталон и подготовить локальный PostgreSQL.
2. Создать TypeScript workspace: Next.js, NestJS, общие контракты и decimal-расчёт.
3. Добавить миграцию, вход, tenant-проверки, машины, рейсы и снимки расчётов.
4. Создать русский интерфейс и синтетические организации Север / Вектор.
5. Проверить эталон, ограничения БД, API двух организаций, сборку и браузер.

## Принятые решения

- Node.js 24; Next.js 16; NestJS 11; PostgreSQL 17. npm workspaces и lockfile.
  Альтернатива — Docker; он не установлен, поэтому на Windows используем
  переносимый PostgreSQL в игнорируемом work/, без системной службы.
- Локальный вход email/пароль, scrypt, серверные сессии в БД, HttpOnly cookie.
  Альтернатива — внешний OIDC; он потребовал бы отдельной настройки провайдера.
- Одна активная организация на сессию, полученная из membership. Переключатель
  организаций пока не нужен. Регистрация и управление участниками отложены.
- pg и параметризованный SQL вместо ORM: явно видны tenant-фильтры и составные FK.
  Миграции транзакционные и аддитивные; RLS пока не используется.
- Вся сумма в RUB без налогов, decimal.js с точностью 80, версия формулы 1.
  Тариф — неизменяемый пользовательский снимок manual-v1, отдельного справочника нет.
- Все новые рейсы — draft. Назначение машины не резервирует время. Переходы
  статусов, водители, фактические расходы, счета, телеметрия и платежи не входят.
- Создание принимает Idempotency-Key, повтор с тем же телом возвращает исходный
  результат, другое тело — 409. Изменения машины/рейса проверяют version.

## Матрица ролей

| Действие | owner | dispatcher | accountant | viewer |
|---|---|---|---|---|
| Читать машины и рейсы | да | да | да | да |
| Создавать/менять машины и draft-рейсы | да | да | нет | нет |
| Читать и создавать плановые расчёты | да | нет | да | нет |
| Управлять членством | отложено | нет | нет | нет |

Финансовые данные не включаются в общие ответы рейсов. Нет маршрута изменения ролей.

## Приёмка

- Вход → машина → рейс → расчёт; после обновления страницы снимок остаётся в БД.
- Пример 600 км: Total 23980.00, Price 29975.00, Profit 6020.00 RUB.
- Чужие ID при GET/PATCH/расчёте дают 404. Назначение чужой машины запрещено
  API и составным внешним ключом PostgreSQL. Viewer получает 403 на запись.
- Неаутентифицированный запрос — 401; неизвестные/невалидные поля — 400.
- Одновременные повторы не дублируют запись, устаревшая version даёт 409.
- Нулевой пробег/выручка не вызывают деление на ноль; границы и округления тестируются.
- Интерфейс сохраняет ввод при ошибке, показывает загрузку и запрещает двойной submit.

Исходные проверки: python scripts/check_starter.py; python -m unittest discover -s tests -v;
python scripts/calculate_trip.py examples/trip-cost.json.
Реализованные команды приложения: npm run typecheck, npm run lint, npm test,
npm run test:integration, npm run build, npm run db:migrate, npm run db:seed.
Публикация и GitHub не требуются.
